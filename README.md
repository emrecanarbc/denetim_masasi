# denetim_masasi
İç denetim ekipleri için tarayıcıda çalışan, kurulum gerektirmeyen platform prototipi. Planlamadan değerlendirmeye denetim akışı, Word/PDF çıktılı ekler, risk-test-bulgu-rapor zinciri, müdür onayı ve puanlama, kanıt yönetimi, bulgu izleme ve e-posta bildirimleri içerir. Tüm veriler kurgusaldır.
